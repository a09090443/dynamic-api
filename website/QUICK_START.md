# 🚀 Docusaurus 文件網站快速啟動指南

## 3 步驟啟動文件網站

### 步驟 1：進入目錄
```bash
cd website
```

### 步驟 2：安裝依賴（首次執行）
```bash
npm install
```
⏱️ 安裝時間：約 1-2 分鐘

### 步驟 3：啟動開發伺服器
```bash
npm start
```
🌐 瀏覽器會自動開啟 `http://localhost:3000`

## 🌟 Docusaurus 文件特色

### 1. 精美的介面
- 響應式設計
- 自動產生側邊欄導航
- 支援深色/淺色主題切換

### 2. 強大的功能
- 即時搜尋（輸入關鍵字即可搜尋）
- 程式碼語法高亮（Java、JSON、YAML、Bash）
- 自動導航（上一頁/下一頁）

### 3. 便於閱讀
- 清晰的章節結構
- 豐富的表格與列表
- 視覺化流程圖

### 4. 易於維護
- Markdown 格式，易於編輯
- Git 版本控制友善
- 支援多版本文件管理

## 🔧 其他有用的命令

### 建置靜態網站
```bash
npm run build
```
產物位於 `build/` 目錄，可部署至任何靜態網站託管服務。

### 預覽建置產物
```bash
npm run serve
```
預覽建置後的網站（`http://localhost:3000`）

### 清除快取
```bash
npm run clear
```
若遇到問題，可清除 Docusaurus 快取。
