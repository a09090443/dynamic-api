# 目標使用者與利害關係人

## 主要使用者

### 後端開發人員

**使用情境**：
- 開發與部署 JAR 模組
- 配置 Endpoint 與 Restful
- 測試動態載入功能

**使用頻率**：高（每日使用）

**技能需求**：
- Java 開發經驗
- 了解 Spring Boot 與 Web Service 基礎
- 熟悉 JAR 打包流程

---

### 測試人員

**使用情境**：
- 管理 Mock 回應規則
- 切換不同測試情境
- 驗證 API 回應正確性

**使用頻率**：高（每日使用）

**技能需求**：
- 了解 API 測試基礎
- 熟悉 XML 與 JSON 格式
- 能撰寫測試案例

---

### 整合人員

**使用情境**：
- 管理外部系統整合的 API Mock
- 模擬外部系統回應
- 測試系統間整合

**使用頻率**：中（每週使用）

**技能需求**：
- 了解系統整合流程
- 熟悉 SOAP 與 RESTful 協定
- 能閱讀 API 文件

---

## 次要使用者

### 專案經理

**使用情境**：
- 查看系統狀態與部署進度
- 監控專案里程碑
- 了解功能使用情況

**使用頻率**：低（每週使用）

**技能需求**：
- 基本 UI 操作能力
- 了解專案管理概念

---

### 維運人員

**使用情境**：
- 監控系統健康狀態
- 查看錯誤日誌
- 處理系統故障

**使用頻率**：中（視需求）

**技能需求**：
- 系統運維經驗
- 了解日誌分析
- 熟悉故障排除流程

---

## 利害關係人

### 客戶／業主

**關注重點**：
- 系統能否縮短 API 開發與測試週期
- 投資報酬率（ROI）
- 交付時程與品質

**期待**：
- 提升開發效率 50% 以上
- 降低部署風險
- 簡化測試流程

---

### 合作廠商

**關注重點**：
- 外部系統整合方式
- API 介面穩定性
- 技術支援與文件

**期待**：
- 清楚的整合文件
- 穩定的 API 介面
- 快速的問題回應

---

## 使用者故事（User Stories）

### 後端開發人員

> 身為後端開發人員，
> 我希望能快速部署新版本的 Web Service，
> 以便加速開發迭代，無需等待重啟時間。

**驗收標準**：
- 上傳 JAR 後 3 秒內即可使用新服務
- 不影響現有服務運作
- 部署失敗可立即回滾

---

### 測試人員

> 身為測試人員，
> 我希望能快速切換不同的 Mock 回應，
> 以便測試各種邊界條件與錯誤情境。

**驗收標準**：
- 切換 Mock 回應 < 1 秒
- 可同時管理多個 Mock 規則
- 可預覽 Mock 回應內容

---

### 整合人員

> 身為整合人員，
> 我希望能模擬外部系統的各種回應，
> 以便測試系統整合的穩定性與錯誤處理。

**驗收標準**：
- 可模擬正常與異常回應
- 可設定多種條件匹配規則
- 可追蹤 Mock 使用記錄

---
