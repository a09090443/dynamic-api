## 1. 簡介

### 1.1 文件目的

定義 Dynamic API Manager 應提供的功能與品質要求，作為開發、測試與後續改版的共同基準。本版以「系統目前實際提供的行為」為主要依據；與預期不一致之處標示為**已知問題**並給出需求應有的樣貌。

### 1.2 系統範圍

**要解決的問題**：開發與測試階段常需要依賴尚未完成、不穩定或無法存取的外部 SOAP / REST 服務。Dynamic API Manager 讓團隊以「上傳 JAR + 設定回應」的方式，在不重啟伺服器的前提下快速提供可控的 Mock 服務。

**範圍內**：

- 上傳含 JAX-WS 或 Spring `@RestController` 類別的 JAR，並在執行期發布／撤銷服務。
- 以資料庫維護 Mock 回應，依 `publishUri`、`method`、`condition`、`serviceType` 回傳。
- 提供 Web 管理介面與管理 API。
- 提供 WSDL 轉 Java 原始碼工具。
- 系統重啟後自動恢復已啟用的服務。

**範圍外**：

- 使用者帳號、登入與權限控管。
- 請求內容的自動解析與規則引擎（比對邏輯由 JAR 自行實作）。
- 錄製真實流量、代理轉發到真實服務。
- 多節點部署與資料同步。
