WSDL 轉換

把 WSDL 轉成 Java 物件並打包成 ZIP 下載，作為撰寫 Endpoint 實作的起點。

  1. 1
    提供 WSDL網址或檔案擇一
  2. 2
    下載 ZIP內含產生的 Java 原始碼
  3. 3
    實作並打包 JAR在自己的專案完成
  4. 4
    新增 Endpoint上傳 JAR 後發布
